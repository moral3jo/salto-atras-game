# ui-flechas

- Workflow: ComfyUI `GameAssets/Fondos (Klein 4B)` (FLUX.2 Klein 4B, 4 pasos)
- Semilla: 902
- Tamaño: 1792x1152

## Estilo

Old engraving style: fine etched ink hatching and cross-hatching like a 19th-century steel engraving, limited warm palette of sepia, burnt ochre, dusty terracotta and cold blue-grey, paper grain. Soft light from the left.

## Cámara

Game interface asset sheet: separate objects arranged in a neat grid with wide empty space between them, each seen perfectly straight from the front, flat, no perspective, on a perfectly plain flat light grey background.

## Escena

Objects: Victorian engraved pointing hands (manicules) and arrows for a game interface: a hand in a white cuff with the index finger pointing right; the same hand pointing left; a slim ornamental engraved arrow pointing right; a slim ornamental engraved arrow pointing left. No text, no letters.
